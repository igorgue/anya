==============================================================================
1. Introduction                                                  *agent-intro*

agent.nvim is an AI assistant plugin for Neovim, powered by the OpenAI Agents
SDK. It provides a split-window interface where you can chat with an agent
that has access to your codebase.

Features:
- Chat interface with streaming responses.
- Access to file system (read, list, search).
- Code editing capability (make changes via SEARCH/REPLACE blocks).
- Context awareness via `@file` mentions.
- Project-specific instructions via `AGENTS.md`.

==============================================================================
2. Installation                                                *agent-install*

Using lazy.nvim:
>lua
    {
        "igor/agent.nvim",
        build = ":UpdateRemotePlugins",
        cmd = "AgentOpen",
    }
<

After installation, run:
    :AgentInstall

This will create a virtual environment and install the necessary Python
dependencies (`openai-agents`, `pynvim`, `openai`).

Ensure you have your OpenAI API key set in your environment:
    export OPENAI_API_KEY="sk-..."

==============================================================================
3. Usage                                                         *agent-usage*

1. Open the agent interface:
    :AgentOpen

2. Type your query in the bottom prompt buffer.
   - Use `@file` to reference files (e.g., `@README.md`).
   - Press `<C-x><C-u>` (or your completion key) to autocomplete file paths.

3. Press `<Enter>` to submit.

4. The agent will stream its response in the top content buffer.

5. If the agent makes code edits, they will appear as SEARCH/REPLACE blocks.
   Review them and use the toolbar to accept or reject the changes.

6. To cancel a running request, press `<C-c>` or use the `/cancel` command.

Slash Commands:
    /clear      Clear the chat history.
    /cancel     Cancel the current agent request.
    /help       Show help message.

==============================================================================
4. Commands                                                   *agent-commands*

:AgentOpen                                                        *AgentOpen*
    Opens the agent interface (Content and Prompt buffers).

:AgentInstall                                                  *AgentInstall*
    Installs Python dependencies in a local virtual environment.

:AgentTestImport                                            *AgentTestImport*
    Verifies that dependencies can be imported.

:AgentCancel                                                    *AgentCancel*
    Cancels the currently running agent request.

==============================================================================
5. Configuration                                                *agent-config*

Project Instructions:
    Create a file named `AGENTS.md` or `.agent/instructions.md` in your
    project root. The content of this file will be prepended to the agent's
    system instructions.
